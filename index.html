Satoshi Shell

Remove the mystery. Anyone can audit the Bitcoin network with the same simple commands a node understands. Try a question, type a command, or just read the output.

What is the total supply of Bitcoin?

See how many bitcoins have been issued so far.

bitcoin-cli gettxoutsetinfo

How many blocks are there?

The current block height of the timechain.

bitcoin-cli getblockcount

Is the mempool busy?

Count pending transactions and total fees waiting.

bitcoin-cli getmempoolinfo

How much security backs the network?

Estimate the current network hashrate.

bitcoin-cli getnetworkhashps

Why We Created Satoshi Shell

Most people think auditing Bitcoin means trusting a company, reading a headline, or running a full node. We built Satoshi Shell to show that the same simple commands a node uses are open, understandable, and verifiable by anyone — no special hardware required.

Type a command, click a question, or just read the output. The goal is to remove the mystery and leave you with one belief: you do not have to trust anyone to verify Bitcoin.
